## DICT-1.5 — Front-end guard: reject accessor/rust for dictionary fields (2026-08-28)

**Forcing tests:** `GenErrors.DictionaryRejectedBy_accessor` / `_rust` → 🟢 (⚪ → 🔴 → 🟢). RED-FIRST: before the guard the plugin exited 0 on `coverage_dictionary.proto` and emitted an accessor that would mis-read the column.
**Design:** `plans/DICT-1.5-backend-support-guard.md` · Step-2: APPROVE at cycle 2 (3 blocking + 2 required → 0).
**What landed:** a file-local `FindDictionaryField` predicate added **inside GIR-10's existing `ValidateBackendsSupportFields` field loop** (`protoc/src/generator.cpp`) — no second validation mechanism. It is **IR-based**, reads the live carrier `ir::FieldFacts.dictionary`, and descends **unconditionally** (an interior `dictionary == false` is not authoritative — spec §7.1's per-shape table). Error names the option, the field FQN, and round RIR. Runs front-end, after `ValidateNoUnsupportedIr` (#55) so a genuinely unsupported type still reports its own error first.
**Why IR-based and not descriptor-based:** schema emission derives dictionary-ness from the same IR, so the guard's inspected node set is a **superset** of the set emittable-as-dictionary — no false negatives, and a descriptor walk would only add false positives. Verified by the step-2 reviewer: `facts.dictionary` is written at only `ir.cpp:62` and `:295` repo-wide, and all twenty `BaseFacts(` sites appear in the design's closed-set table.
**The DICT-1 wrapper hole does NOT apply here** — that is a *projection*-level hole in `GatherFieldsImpl` / `BuildFlattenedFieldListImpl`, and this pass uses neither: it calls `ir::BuildFieldIr(msg->field(i))` directly, so `BaseFacts(w)` at `ir.cpp:545` reads a `flatten_field` wrapper's own option. Verified in the tree, not assumed. The one IR-invisible shape (spec §7.1 gap 2, `BuildFlattenedRepeated` inner-declared) is safe **by construction**: emission drops the fact identically, so there is no mis-read to guard against.
**Files touched:** `protoc/src/generator.cpp`, `protoc/include/type_mapper.hpp`, `docs/{dictionary-option-spec.md,fletcher-options.md}`, `integration-tests/protoc-coverage/{CMakeLists.txt,cmake/run_backend_guard_check.cmake}`; new fixtures `coverage_dictionary{,_wkt,_flatten,_field_flatten,_unsupported,_struct_child,_struct_child_inner,_list_child,_map_child}.proto`. **Zero diff** to `recordbatch_accessor_emitter.*`, Rust emission, `ir.*`, `option_reader.*`, `cpp_backend_*`.
