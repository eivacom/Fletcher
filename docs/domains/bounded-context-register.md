# Bounded-context register

A bounded context is a question the running system answers where two places answering differently
would be a defect: a rule, not a mechanism. Each row names the **single site** allowed to answer
it, a **structural test** that fails on a violation nobody listed, and a build-state mark scoped to
what is actually built.

Created 2026-11-10 by the D7F pre-round census ([docs/archive/D7F/D7F-pre-round-audit.md](../archive/D7F/D7F-pre-round-audit.md),
part B). BC-1, BC-5 and BC-6 are adapted to the later owner ruling that every batch callback runs on
the batch thread (domain 7 D10). A new row is added whenever a round's census finds a question with
no row. A change to a row's single site needs the round that changes it to say so. BC-10 to BC-15
were added by the D9S pre-round census (2026-11-13, [docs/archive/D9S/D9S-pre-round-audit.md](../archive/D9S/D9S-pre-round-audit.md),
part D) for domain 9, the C ABI shim; BC-12's site was ruled by the owner the same day. BC-16 and BC-17
were added by the D10C pre-round census (2026-11-15, [plans/D10C-pre-round-audit.md](../../plans/D10C-pre-round-audit.md),
part E) for domain 10, the C# binding, with C# notes on BC-2, BC-8, BC-9, BC-10, BC-12, BC-13 and BC-14.
